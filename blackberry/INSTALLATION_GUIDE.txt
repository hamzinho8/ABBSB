NOUVEAUTÉS VERSION 1.2.0 (SYNCHRONISATION CONTACTS VIP) :
-----------------------------------------------------------------------------
1. Gestion des Contacts VIP Restreints (ex: 10 favoris Android) :
   - Évite d'encombrer la mémoire limitée du BlackBerry Curve 9300.
   - Réception de la commande 'CONTACTS_CLEAR' : vidage instantané de la mémoire
     et du RecordStore (RMS) local.
   - Réception de 'CONTACTS_START|<nombre>|VIP' : initialisation du lot et statut
     en direct ("Réception de X contacts VIP...").
   - Réception de 'CONTACT|<id>|<nom>|<numero>' : décodage et ajout dynamique.
   - Réception de 'CONTACTS_END|<nombre>' : enregistrement dans la base persistante
     RecordStore (RMS), rafraîchissement d'écran et message modal informatif :
     Dialog.inform("X contacts VIP synchronisés avec succès !").

2. Persistance Hors Ligne (RecordStore RMS) :
   - Stockage local dans la mémoire flash du BlackBerry (base "BBSB_VIPContacts").
   - Vos contacts VIP restent disponibles même lorsque le smartphone est déconnecté
     ou après redémarrage du Curve 9300.

3. Interface VIP Optimisée Curve 9300 (320x240) :
   - Étoile dorée ★ et badge [VIP], affichage en 2 lignes (Nom en gras + Numéro).
   - Recherche rapide en temps réel lors de la frappe dans la barre de recherche.
   - Appel direct par appui sur la touche d'appel verte ou clic Trackpad.
   - Menu contextuel :
     * "Appeler via Android"
     * "Demander les contacts VIP" (envoie GET_CONTACTS & SYNC_CONTACTS)
     * "Sauvegarder dans carnet BB" (enregistre directement dans le carnet natif via JSR 75 PIM)
     * "Vider les contacts VIP"

NOUVEAUTÉS VERSION 1.1.0 :
-----------------------------------------------------------------------------
1. Amélioration de 'Find My Phone' (Arrêt distant depuis le smartphone) :
   - Interception automatique des paquets 'PHONE_FOUND' et 'FIND_PHONE_STOPPED'

2. Module de Télémesure Réseau & Signal du smartphone (CELL_TELEMETRY) :
   - Réception et décodage en temps réel des paquets envoyés par Android :
     CELL_TELEMETRY|Operateur|TypeReseau|SignalBars|StatutInternet
     (ou NETWORK_STATUS|...)
   - Affichage direct sur l'écran d'accueil du BlackBerry (Curve 9300, 320x240) :
     Exemple : [5G] Orange F - Signal : [||||] (En ligne)
     Si le signal vaut 3 : [|||.] / 2 : [||..] / 1 : [|...] / 0 : [....]
   - Code couleur dynamique : Cyan vif en ligne (ONLINE), Orange hors-ligne (OFFLINE).
   - Option de Menu "Rafraîchir le réseau" : envoie la commande GET_NETWORK via Bluetooth
     pour obtenir instantanément l'état réseau le plus récent du smartphone.

1. EXPLICATION DE L'ANOMALIE BLUETOOTH (LED BLEUE CLIGNOTANTE) :
-----------------------------------------------------------------------------
Sur votre BlackBerry Curve 9300, l'application s'ouvrait correctement avec la 
mention "[BT: WAIT]", mais la LED bleue clignotait sans cesse et rien ne se 
passait sur l'application Android ("BB Compagnon").

D'OÙ VENAIT CE COMPORTEMENT ?
1. Inversion Rôle Serveur / Client :
   - Dans votre application Android ("BB Compagnon" / Système Bridge), l'écran
     affiche la liste des appareils Bluetooth scannés ou jumelés ("BlackBerry 9300").
   - Lorsque vous cliquez sur "BlackBerry 9300" sur votre smartphone Android,
     votre Android agit en CLIENT Bluetooth RFCOMM et tente d'ouvrir une socket
     vers le BlackBerry.
   - Mais sur le BlackBerry, l'ancienne version exécutait une recherche cliente 
     infinie ("startInquiry") au lieu de démarrer un SERVEUR d'écoute !
   - Le BlackBerry n'écoutait sur aucun port RFCOMM (aucun serveur "StreamConnectionNotifier"
     n'était actif). La tentative de connexion depuis l'Android échouait donc
     instantanément ("Connexion refusée" / "Socket fermé").

2. Conflit Radio et Clignotement de la LED Bleue :
   - L'ancienne boucle d'inquiry ("startInquiry") forçait la radio Bluetooth du
     BlackBerry à émettre des paquets de recherche d'appareils en permanence,
     ce qui déclenchait le clignotement continu de la LED bleue.
   - Pire : sur les puces Bluetooth (comme celle du Curve 9300), le mode Inquiry actif
     sature la radio et bloque la réception des paquets de connexion ("Page Scan")
     émis par l'Android !

2. SOLUTIONS APPORTÉES DANS LA VERSION 1.0.9 :
=============================================================================
1. Serveur Bluetooth RFCOMM Dédié (BluetoothServer.java) :
   - Le BlackBerry démarre désormais un vrai serveur d'écoute Bluetooth SPP
     dès l'ouverture de l'application.
   - Il écoute en continu sur l'UUID personnalisé utilisé par votre application Android :
     UUID: 27B4426543A74744A6F1C20531AE40F1 (27b44265-43a7-4744-a6f1-c20531ae40f1)
   - Un écouteur de secours est également activé sur l'UUID SPP standard (0x1101).
   - Plus de boucle "startInquiry" bloquante : la LED ne clignotera plus dans le vide !

2. Négociation et Protocole BSB/1 Fiabilisés :
   - Dès la connexion depuis l'Android, le BlackBerry accepte instantanément la liaison,
     envoie la négociation "HELLO|BSB/1|BLACKBERRY_9790" puis "READY", et échange les
     niveaux de batterie ("BATTERY|<niveau>", "GET_PHONE_BATTERY").
   - L'écran du BlackBerry bascule immédiatement de "[BT: WAIT]" à "[BT: ON]" (vert).
   - L'application Android affiche le BlackBerry connecté.

3. Options Manuelles Ajoutées au Menu BlackBerry :
   - Appuyez sur la touche MENU BlackBerry (logo BB à gauche du trackpad) :
     * "Relancer Bluetooth" : réinitialise proprement le serveur d'écoute.
     * "Connecter à l'Android" : tente une connexion vers les appareils déjà jumelés
       dans les réglages du BlackBerry (sans balayage radio intrusif).

3. PROCÉDURE DE JUMELAGE ET DE CONNEXION ÉTAPE PAR ÉTAPE :
=============================================================================
Pour assurer une liaison parfaite entre votre Curve 9300 et votre smartphone Android :

ÉTAPE A : Jumeler une bonne fois pour toutes les deux téléphones dans l'OS
1. Sur le BlackBerry Curve 9300 :
   - Allez dans : "Gérer les connexions" > Cochez "Bluetooth".
   - Allez dans : "Options Bluetooth" (ou Options > Réseaux et connexions > Connexions Bluetooth).
   - Réglez "Détectable" (Discoverable) sur : "Oui" (Yes).
2. Sur votre Smartphone Android :
   - Allez dans les Paramètres Bluetooth d'Android.
   - Cliquez sur "Associer un nouvel appareil".
   - Sélectionnez "BlackBerry 9300".
   - Confirmez le code PIN / le mot de passe sur les deux écrans (ex: 0000 ou 1234).
   - Une fois associé, ils sont officiellement jumelés.

ÉTAPE B : Autoriser les connexions sur le BlackBerry
1. Sur le BlackBerry Curve 9300, dans "Appareils Bluetooth jumelés" :
   - Mettez en surbrillance votre smartphone Android.
   - Touche MENU BlackBerry > "Propriétés de l'appareil".
   - Réglez "Approuvé" (Trusted) sur : "Oui".
   - Cela évitera les demandes de confirmation intempestives.

ÉTAPE C : Lancer l'application SmartBridge
1. Installez et ouvrez SmartBridge v1.0.9 sur votre BlackBerry Curve 9300.
   - En haut à gauche, vous verrez "[BT: WAIT]". Le serveur Bluetooth est en écoute.
2. Ouvrez l'application "BB Compagnon" (Système Bridge) sur votre smartphone Android.
3. Dans la liste des appareils Bluetooth qui s'affiche, touchez :
   "BlackBerry 9300".
4. MAGIE : 
   - Le statut passe à "[BT: ON]" en vert sur le BlackBerry !
   - Le pourcentage de batterie de votre smartphone Android s'affiche : "[Ph: xx%]".
   - Les notifications (SMS, WhatsApp, appels) et contrôles multimédias sont actifs !

4. COMMENT INSTALLER LA MISE À JOUR v1.0.9 SUR LE CURVE 9300 :
=============================================================================
Méthode Carte SD (Très simple) :
1. Téléchargez "BBSB_BlackBerry_Curve_9300_v1.0.9.zip" (ou récupérez BBSmartBridge.jad et .cod).
2. Copiez les deux fichiers sur votre carte Micro SD dans un dossier (ex: SDCard/BBSB/).
3. Sur votre Curve 9300, ouvrez "Médias" ou "Fichiers" > Touche MENU > "Explorer".
4. Allez dans le dossier et cliquez sur "BBSmartBridge.jad".
5. Cliquez sur "Télécharger" / "Remplacer" pour installer la v1.0.9.
6. Lancez SmartBridge !
