=============================================================================
GUIDE D'INSTALLATION & DE DÉPANNAGE - SmartBridge v1.0.7
BlackBerry Curve 9300 / OS 5.0 - OS 6.0
=============================================================================

1. EXPLICATION DE L'ERREUR RÉSOLUE ("attempts to access a secure API") :
-----------------------------------------------------------------------------
Sur votre BlackBerry Curve 9300, l'application s'installait bien avec son nom 
et son icône, mais affichait au lancement :
"Module 'BBSmartBridge' attempts to access a secure API" (ou "tente d'accéder à 
une API sécurisée").

POURQUOI CETTE ERREUR ?
Le système BlackBerry OS (RIM) protège certaines fonctions matérielles 
(net.rim.device.api.notification.NotificationsManager, Alert, LED). 
Pour exécuter ces bibliothèques sur un vrai terminal physique, RIM exigeait 
une signature cryptographique via des serveurs officiels BlackBerry (fichiers RBB, RCR, RRT).
Comme les serveurs de signature BlackBerry sont définitivement fermés, toute 
application qui appelle ces classes est systématiquement bloquée par l'OS physique.

SOLUTION APPORTÉE DANS LA VERSION 1.0.7 :
1. Suppression intégrale des dépendances aux API fermées et restreintes (LED, NotificationsManager, Alert).
2. Remplacement par les API audio standard et ouvertes Java ME MMAPI (javax.microedition.media.Manager et playTone).
3. Déclaration explicite des autorisations Bluetooth (MIDlet-Permissions: Connector.bluetooth.client/server).
4. L'application SmartBridge v1.0.7 est désormais 100% autonome, libre de toute signature RIM et peut s'ouvrir instantanément sur votre Curve 9300 !

=============================================================================
2. ÉTAPE PRÉALABLE INDISPENSABLE : DÉSINSTALLER LA VERSION 1.0.6
=============================================================================
Avant d'installer la nouvelle version v1.0.7 :
1. Sur votre BlackBerry Curve 9300, allez dans :
   Options (icône clé à molette) > Applications (ou Gestion des applications).
2. Repérez "SmartBridge".
3. Appuyez sur la touche MENU BlackBerry (à gauche du pavé tactile/trackpad).
4. Sélectionnez "Supprimer" (Delete) et confirmez.
5. Redémarrez le BlackBerry (retirez et remettez la batterie, ou pressez 
   Alt + Majuscule Gauche + Suppr).

=============================================================================
3. RÉGLAGE DES PERMISSIONS APRÈS INSTALLATION (TRÈS IMPORTANT)
=============================================================================
Une fois la version 1.0.7 installée sur votre Curve 9300 :
1. Allez dans : Options > Applications (ou Gestionnaire d'applications).
2. Sélectionnez "SmartBridge".
3. Appuyez sur la touche MENU BlackBerry > "Modifier les autorisations" (Edit Permissions).
4. Définissez :
   - Connexions (Connections) -> AUTORISER (Allow)
   - Interactions -> AUTORISER (Allow)
   - Données utilisateur (User Data) -> AUTORISER (Allow)
5. Appuyez sur la touche ÉCHAP / Retour et choisissez "Enregistrer" (Save).
Cette étape garantit que le Bluetooth et le stockage fonctionnent sans blocage.

=============================================================================
4. MÉTHODES D'INSTALLATION DE LA VERSION 1.0.7
=============================================================================

--- MÉTHODE 1 (RECOMMANDÉE SANS PC) : VIA CARTE MÉMOIRE (SD CARD) ---
1. Téléchargez le nouvel artefact ZIP généré par GitHub Actions : 
   "BBSB_BlackBerry_Curve_9300_v1.0.7.zip" et décompressez-le.
2. Copiez TOUS les fichiers suivants dans un même dossier sur votre carte micro SD 
   (par exemple : SDCard/BBSB/) :
   - BBSmartBridge.jad
   - BBSmartBridge.cod (et tout éventuel BBSmartBridge-*.cod)
3. Insérez la carte micro SD dans votre BlackBerry Curve 9300.
4. Ouvrez l'application "Médias" ou "Fichiers".
5. Appuyez sur la touche MENU BlackBerry > "Explorer" (Parcourir les fichiers).
6. Naviguez dans : Carte mémoire > BBSB.
7. Cliquez sur "BBSmartBridge.jad".
8. L'écran officiel d'installation affiche :
   - Nom : SmartBridge
   - Version : 1.0.7
   - Fournisseur : Hamza
   - Icône : Logo SmartBridge
9. Cliquez sur "Télécharger" ou "Installer".

--- MÉTHODE 2 (PC DIRECT VIA USB) : AVEC BBSAK OU VNBBUTILS ---
1. Connectez votre BlackBerry Curve 9300 au PC en USB.
2. Lancez BBSAK ou vnbbUtils.
3. Cliquez sur "Connect".
4. Dans "Install CODs" (ou "Load COD"), sélectionnez "BBSmartBridge.cod".
5. L'application est chargée directement.

--- MÉTHODE 3 : VIA BLACKBERRY DESKTOP SOFTWARE ---
1. Connectez le BlackBerry au PC.
2. Ouvrez BlackBerry Desktop Software.
3. Allez dans "Applications" > "Importer".
4. Sélectionnez le fichier "BBSmartBridge.alx".
5. Cliquez sur "Appliquer".

Profitez de votre application SmartBridge v1.0.7 sur votre BlackBerry Curve 9300 !
